## Claude's challenges and flags
1. **Strategy tension (needs a decision).** D1 positioned this as *unofficial/complementary*, but the goal is *government-owned, government-funded*. These can coexist only as a two-stage path: build a credible pilot independently -> win official endorsement/adoption as the **host-country layer** (precedent: COP28 had a separate host-government "COP28 UAE" app next to UNFCCC's). Branding must not imply endorsement until granted.
2. **Attendance figure.** User cites >80k; press reports ~50,000 (unconfirmed, see reality-check.md §C). Don't size infrastructure or pitch on either number until an official figure exists; plan for a range.
3. **No budget with a 6-person team.** Unclear who pays salaries until grants/contract arrive. This is the largest delivery risk; funding strategy (Phase 17) must be started early, in parallel with discovery.
4. **No official data access.** Schedules, accreditation and venue data are controlled by UNFCCC/host. A pilot needs either partnership or content we can legitimately build ourselves (public info, Ethiopian context, climate education).
5. **Ethiopian data law.** Proclamation 1321/2024 (in force July 2024) reportedly requires locally collected personal data be stored on servers in Ethiopia and appointment of a DPO. Sources are secondary (policy trackers/law-firm blogs) — **verify in Phase 13**; it directly constrains cloud/architecture choices.
6. **"Recognized globally" is not measurable.** Needs concrete proxies (e.g., listed/linked from official COP32 or UNFCCC channels, user count, press coverage). To define in Phase 2.
7. **Stop conditions.** "Someone else officially established" should be a *pivot trigger* (partner/integrate/niche) before it is a stop. Suggest adding dated go/no-go checkpoints (e.g., re-check official announcements quarterly; funding/endorsement gate by a set date).
8. **Pitch readiness.** Government approach likely needs registered company, a demo, and a letter-of-support path. Unknown: which office is "dedicated" (Digital/ICT Task Force? MinT? Foreign Ministry/COP32 secretariat?). Open question.
